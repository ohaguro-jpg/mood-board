# MOOD BOARD

集めた画像を並べて、見比べるためのムードボード。
**画像の実体をこの端末の中に保存する**ので、元が消えても手元に残ります。

https://ohaguro-jpg.github.io/mood-board/

**外部ライブラリ・外部サーバーはゼロ。** ネットが切れていても最後まで動きます。

## できること

**集める**
- スマホの写真から（複数選択）
- 画像のURLから（何行でも）
- Pinterestからまとめて（後述）
- PCからドラッグ&ドロップ

**並べる**
- 自由配置のキャンバス。指でドラッグ、ピンチで拡大、角をつまんでリサイズ
- 指を離しても滑る。ボードを開くと中心から外へ順に立ち上がる
- 隣のものと**そろう位置で吸い付く**（整列ガイドが出る。option で一時解除）
- **そろえる** — 左右上下・中央・等間隔・幅や高さをそろえる・横一列／縦一列／重ねる
- 「ならべる」で石積み整列、**色の順に整列**、**区分けごとにまとめる**
- ボード全体の代表6色をパレットとして表示

**見比べる**
- **みくらべ** — 2〜6枚を全画面分割（よこ／たて／格子）、各セル独立でズーム
- **かさねる** — 2枚をスライダーで重ねて比べる
- Pinterest風のグリッド表示（右上で切替。グリッドのままでも「みくらべ」できる）

**書き込む・整理する**
- **文字を置く** — 付箋のような文字カード。画像と同じようにドラッグ・リサイズできる
- **色を置く** — 色見本を盤面に置ける。1枚表示の「色をとる」で写真の色から作れる
- **タグ** — 押すだけで付け外し。選んだ複数枚にまとめて付けられる
- **ひとこと / 説明** — 写真の下に出る短い言葉と、長めの文章
- **区分け** — ボードの中のグループ。見出し付きの段に並べ替えられる
- **さがす** — メモ・文字・タグの文字で絞り込み、色からも絞り込める。外れたものは薄く沈む
- **重複をさがす** — 似ている写真をまとめて見つけて、まとめてゴミ箱へ

**直す**
- **切り抜き**
- **まわす** — 90度ずつ
- **元にもどす / やり直す** — ⌘Z・⇧⌘Z。40手ぶん
- ゴミ箱は戻せる削除。本当に消えるのは「ゴミ箱を空にする」だけ

**持ち出す**
- USBに書き出す → 挿したパソコンで `index.html` を開けばそのまま広がる（オフライン可）
- **USBとつなぐ** — どちらに何が足りないかを枚数とサムネで見せてから同期する
- 1枚の画像にして送る（LINEやメールにそのまま貼れる）
- **PDFにして送る** — 盤面の配置のまま1ページ／1枚ずつ
- 印刷 — A4・A3のたて／よこ、余白、格子の列数、白黒。**選んだものだけ**も刷れる
- まるごとZIPでバックアップ、別の端末に復元

**好みに合わせる（歯車）**
- 背景（くろ／グレー／しろ／紙）・ドット・影・すきま・文字の大きさ
- 吸い付きの入切、2本指の割り当て、動きの量

## Pinterestからまとめて取り込む

Pinterestの画像は**Pinterestのページの中からしか取り出せません**（CORSの制限）。
そのため、あちら側で集めてから持ち帰る形にしています。

1. パソコンのChromeで自分のボードを開く
2. アプリの「いれる → Pinterestからまとめて」でコードをコピーし、Console に貼る
3. 自動で最後までスクロールしながら集め、縮小して1つのZIPにまとめます
4. アプリの「メニュー → ZIPから読み込む」に入れると、ボード名も並びも復元されます

## 技術メモ

- 外部ライブラリ・外部サーバー・CDNはゼロ。ZIPとPDFの読み書きも自前
- 画像は IndexedDB に保存し、起動時に永続保存を申請
- 取り込み時に長辺1800px / WebP へ作り直す（実測で 11.66MB → 1.15MB）
- 切り抜きと回転は焼き込み方式。同じ向きは作り置きを使い回して増殖を防ぐ
- HEIC は Safari なら読める（Chromium系は不可のため `accept` を具体型に絞っている）
- PWA。ホーム画面に置けばオフラインでも起動します
