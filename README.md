# MOOD BOARD

集めた画像を並べて、見比べるためのムードボード。
**画像の実体をこの端末の中に保存する**ので、元が消えても手元に残ります。

https://ohaguro-jpg.github.io/mood-board/

**外部ライブラリ・外部サーバーはゼロ。** ネットが切れていても最後まで動きます。

## できること

**集める**
- スマホの写真から（複数選択）
- 画像のURLから（何行でも）
- Pinterestからまとめて（後述）
- PCからドラッグ&ドロップ

**並べる**
- 自由配置のキャンバス。指でドラッグ、ピンチで拡大、角をつまんでリサイズ
- 指を離しても滑る。ボードを開くと中心から外へ順に立ち上がる
- 隣のものと**そろう位置で吸い付く**（整列ガイドが出る。option で一時解除）
- **そろえる** — 左右上下・中央・等間隔・幅や高さをそろえる・横一列／縦一列／重ねる
- 「ならべる」で石積み整列、**色の順に整列**、**区分けごとにまとめる**
- ボード全体の代表6色をパレットとして表示

**見比べる**
- **みくらべ** — 2〜6枚を全画面分割（よこ／たて／格子）、各セル独立でズーム
- **かさねる** — 2枚をスライダーで重ねて比べる
- Pinterest風のグリッド表示（右上で切替。グリッドのままでも「みくらべ」できる）

**書き込む・整理する**
- **文字を置く** — 付箋のような文字カード。画像と同じようにドラッグ・リサイズできる
- **色を置く** — 色見本を盤面に置ける。1枚表示の「色をとる」で写真の色から作れる
- **タグ** — 押すだけで付け外し。選んだ複数枚にまとめて付けられる
- **ひとこと / 説明** — 写真の下に出る短い言葉と、長めの文章
- **区分け** — ボードの中のグループ。見出し付きの段に並べ替えられる
- **さがす** — メモ・文字・タグの文字で絞り込み、色からも絞り込める。外れたものは薄く沈む
- **重複をさがす** — 似ている写真をまとめて見つけて、まとめてゴミ箱へ

**直す**
- **切り抜き**
- **まわす** — 90度ずつ
- **元にもどす / やり直す** — ⌘Z・⇧⌘Z。40手ぶん
- ゴミ箱は戻せる削除。本当に消えるのは「ゴミ箱を空にする」だけ

**持ち出す**
- USBに書き出す → 挿したパソコンで `index.html` を開けばそのまま広がる（オフライン可）
- **USBとつなぐ** — どちらに何が足りないかを枚数とサムネで見せてから同期する
- 1枚の画像にして送る（LINEやメールにそのまま貼れる）
- **PDFにして送る** — 盤面の配置のまま1ページ／1枚ずつ
- 印刷 — A4・A3のたて／よこ、余白、格子の列数、白黒。**選んだものだけ**も刷れる
- まるごとZIPでバックアップ、別の端末に復元

**好みに合わせる（歯車）**
- 背景（くろ／グレー／しろ／紙）・ドット・影・すきま・文字の大きさ
- 吸い付きの入切、2本指の割り当て、動きの量

## スマホで使う

**iPhone**
1. Safari で https://ohaguro-jpg.github.io/mood-board/ を開く
2. 共有ボタン →「ホーム画面に追加」。以後はアプリのように全画面で開けて、ネットが無くても動きます
3. 写真は、その iPhone の中にだけ保存されます（どこにも送られません）

**Android**
1. Chrome で https://ohaguro-jpg.github.io/mood-board/ を開く
2. 右上のメニュー（︙）→「アプリをインストール」（または「ホーム画面に追加」）。ホーム画面とアプリ一覧に入り、全画面で開きます
3. ほかのアプリ（Google フォト・Instagram・Chrome など）の「共有」→「MOOD BOARD」で、写真や動画をストックに送れます
4. 戻るボタンで、開いているシートや1枚表示を1つずつ閉じます。アイコンを長押しすると「ストック」「新しいボード」へすぐ行けます

プライバシーポリシー：https://ohaguro-jpg.github.io/mood-board/privacy.html （写真や情報は集めません。どこにも送りません）

Mac とスマホの写真のやりとりは、iCloud 写真・Google フォト・Amazon Photos に任せます。
Mac版の「送る › 写真アプリに入れる」や「クラウド用フォルダに置く」で入れて、スマホ版では「いれる › スマホの写真から」で選びます。

## 2026年10月に増えたもの

- **インスタで試す**（ホームの「インスタ」）— インスタのプロフィールそっくりの画面に写真を3列で並べ、上げたらどう見えるかを試す。
  ドラッグで並べ替え・ぼかして見る／白黒で見る・白い画面／黒い画面・パズル（3・6・9枚に分ける）・キャプションの下書き。
  グリッドは今のインスタと同じ 3:4。投稿用の写真を投稿する順に 1080×1440 で書き出せる（インスタには何も送らない）

- **しるし ◎本命・○候補・△保留・✕見送り** — 比べて選ぶための目印。1〜4キー、右のパネル、1枚表示の丸ボタンで。くらべるシートにも出ます
- **1枚ずつ見て選ぶ** — 大きく見ているとき ←→（スマホは左右に払う）で前後へ。見ながら しるし を付けられます
- **ストックの並べ替え** — 新しい順・古い順・しるし順・色の順・ランダム（ふと見返す）。縦長／横長／正方形、色の丸でしぼる。小・中・大
- **色味が近い順** — 1枚選んで、その写真に色が近いものから並べる
- Android でアプリとしてインストール・共有メニューから取り込み・戻るボタン

- 写真を押すと右（スマホでは下）に設定パネル：ひとこと・タグ・大きさ・不透明度・反転などをその場で
- ストック：取り込んだ写真の全部を1か所で。ボードに載せずに貯めておける
- 送る：番号付きの「くらべるシート」（PDF）・1枚の画像・写真そのまま。スマホでは共有メニュー（LINE・AirDrop・写真に保存）へ
- 付箋の色・描いた線の色と太さ／動画（表紙に ▶。押すと再生）
- 英語（設定 › 言語 / Language）／使い方（右上の ？）

## Pinterestからまとめて取り込む

Pinterestの画像は**Pinterestのページの中からしか取り出せません**（CORSの制限）。
そのため、あちら側で集めてから持ち帰る形にしています。

1. パソコンのChromeで自分のボードを開く
2. アプリの「いれる → Pinterestからまとめて」でコードをコピーし、Console に貼る
3. 自動で最後までスクロールしながら集め、縮小して1つのZIPにまとめます。
   **集めている間は「✋ 触らないでください」の札が出ます。Chrome を前に出したまま待ってください**
   （ほかのアプリやタブに切り替えると Chrome が止めてしまうため。止まっても戻れば続きから集めます）
4. アプリの「メニュー → ZIPから読み込む」に入れると、ボード名も並びも復元されます

## 技術メモ

- 外部ライブラリ・外部サーバー・CDNはゼロ。ZIPとPDFの読み書きも自前
- 画像は IndexedDB に保存し、起動時に永続保存を申請
- 取り込み時に長辺1800px / WebP へ作り直す（実測で 11.66MB → 1.15MB）
- 切り抜きと回転は焼き込み方式。同じ向きは作り置きを使い回して増殖を防ぐ
- HEIC は Safari なら読める（Chromium系は不可のため `accept` を具体型に絞っている）
- PWA。ホーム画面に置けばオフラインでも起動します
